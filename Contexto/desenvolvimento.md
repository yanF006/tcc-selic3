# Instruções para o desenvolvimento

Confirmar tecnologias a serem utilizadas. Não pesquisar em outras pastas com nome parecido a essa (exemplo: tcc-selic2, SELIC)

## Tecnologias

Tenho experiência em: 
- HTML 
- CSS 
- JavaScript 
- Node.js 
- MySQL 
- Java 
- Phyton 
- C 
- C++ 
- C#

Diante disso, as tecnologias recomendadas são:


| Área               | Tecnologia                                   | Motivo                                                         |
| ------------------ | -------------------------------------------- | -------------------------------------------------------------- |
| Linguagem          | **TypeScript**                               | Evolução natural do seu JavaScript                             |
| Frontend           | **React**                                    | Excelente para interfaces com muitos formulários e componentes |
| Framework          | **Next.js**                                  | Frontend + backend no mesmo projeto                            |
| Backend            | **Next.js Route Handlers / Server Actions**  | Evita manter um servidor separado                              |
| ORM                | **Prisma ORM 7**                             | Facilita trabalhar com MySQL e relacionamentos                 |
| Banco              | **MySQL**                                    | Você já domina e o PRD já o define                             |
| Autenticação       | **Better Auth**                              | Login, sessões, recuperação de senha etc.                      |
| Validação          | **Zod**                                      | Validação consistente no frontend/backend                      |
| Formulários        | **React Hook Form**                          | Formulários grandes e validações                               |
| CSS                | **Tailwind CSS**                             | Construção rápida e consistente da interface                   |
| Componentes        | **shadcn/ui**                                | Componentes acessíveis e customizáveis                         |
| Documentos         | **Docxtemplater**                            | Já validado no projeto                                         |
| Preview DOCX       | **Docxtemplater + renderização client-side** | Conforme especificação                                         |
| E-mail             | **Nodemailer**                               | Você já conhece Node.js e o PRD prevê isso                     |
| Hospedagem         | **Vercel**                                   | Boa integração com Next.js                                     |
| Banco hospedado    | **Aiven MySQL**                              | Mantém a escolha do PRD                                        |
| Controle de versão | **Git + GitHub**                             | Você já conhece/está estudando                                 |

## Ordem

Começar pelas telas (frontend). Depois integrar o banco de dados e o backend.
